# Portfolio v1 (archived)

The first version of my personal portfolio website, built in 2022 with Create
React App, React Router and Sass.

**Live archive:** https://ashtagging.github.io/portfolio-v1/
**Current site:** https://ashtagging.com

Kept public as a snapshot of earlier work. Not actively maintained.

## Running locally

```bash
npm install
npm start
```

## Deploying

The site is deployed to GitHub Pages from the `gh-pages` branch, which holds the
output of `npm run build`.
